  In this study, we utilize transfer learning to extract high-level visual features from VR gameplay videos using the InceptionV3 model pre-trained on the ImageNet dataset. These features are then passed to a Long Short-Term Memory (LSTM) network to capture the temporal dynamics of the VR experience and predict cybersickness severity over time.
